# Quase Normal

Laboratórios abertos de estatística e econometria no celular: simulações em que o aluno
escolhe o mundo, sorteia os dados e vê o que a estatística encontra neles. O R roda dentro
do navegador (webR), sem instalar nada.

Site: https://quasenormal.github.io

Site do projeto de extensão **Métodos Quantitativos no Celular: laboratórios interativos e
abertos de estatística e econometria** (UERJ, SIEXT 8515/2026), coordenado por Marcio Gold
Firmo. Licença: CC BY-NC 4.0 (ver `LICENSE`).

Cada laboratório é um arquivo HTML autocontido (`laboratorio-*-webr.html`); `index.html`
é a trilha. Não há etapa de build.
